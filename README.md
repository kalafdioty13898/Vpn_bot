# 🤖 ربات فروش VPN (تلگرام)

ربات حرفه‌ای فروش سرویس VPN با اتصال به پنل مدیریت، کیف پول، پرداخت کارت‌به‌کارت با تأیید رسید، تست رایگان، زیرمجموعه‌گیری و **پنل مدیریت کامل داخل تلگرام**.

## ✨ امکانات

- 🛍 فروش سرویس‌های ثابت (۵ تا ۱۰۰ گیگ) + سرویس دلخواه (حجم/روز دلخواه با قیمت خودکار)
- 💳 پرداخت کارت‌به‌کارت + ارسال رسید + تأیید/رد دستی توسط ادمین
- 💰 کیف پول کاربران + شارژ با تأیید ادمین + پرداخت از کیف پول
- 🎁 تست رایگان (یک‌بار برای هر کاربر)
- 🤝 زیرمجموعه‌گیری با پورسانت درصدی (قابل تنظیم)
- 📦 مدیریت سرویس‌ها (لینک جدید، کپی، حذف) + جستجوی سریع
- 📚 آموزش (قابل ویرایش از پنل) + 🎧 پشتیبانی با امکان پاسخ ادمین
- 🔔 عضویت اجباری در کانال (قابل خاموش/روشن)
- 🛠 **پنل مدیریت کامل داخل تلگرام** (توضیح پایین)
- 🔒 امنیت: Transaction-safe، جلوگیری از پرداخت تکراری، Row Lock، Rate-limit، Audit Log

## 🗂 ساختار پروژه

```
app/
├── main.py                  # نقطه شروع
├── config.py                # خواندن .env
├── logging_conf.py          # لاگ (بدون اطلاعات حساس)
├── db/                      # دیتابیس (SQLAlchemy 2 async)
│   ├── models.py            # همه مدل‌ها
│   └── init_db.py           # ساخت اسکیما + Seed
├── services/                # منطق کسب‌وکار (Handler→Service→DB)
├── vpn/                     # Adapter پنل VPN (mock / pasargad)
├── bot/
│   ├── handlers/            # هندلرهای تلگرام
│   │   └── admin/           # ✅ پنل ادمین کامل
│   ├── keyboards/           # Reply + Inline keyboards
│   ├── middlewares/         # DB session, throttle, access
│   └── states.py            # FSM
└── utils/                   # اعتبارسنجی، فرمت، ID
tests/                       # تست‌های واحد
```

## 🚀 نصب و اجرا (سرور)

```bash
# 1) دانلود پروژه
git clone https://github.com/kalafdioty13898/Vpn_bot.git
cd Vpn_bot

# 2) محیط مجازی + پکیج‌ها
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3) فایل تنظیمات
cp .env.example .env
nano .env      # BOT_TOKEN و ADMIN_IDS را بگذارید (پایین را ببینید)

# 4) اجرا
python -m app.main
```

یا با اسکریپت آماده:

```bash
bash scripts/start.sh
```

### 🔑 Secret ها (.env)

| متغیر | توضیح | مثال |
|---|---|---|
| `BOT_TOKEN` | توکن ربات از @BotFather | `123456:AA...` |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها (اولی = سوپر ادمین) | `8581608010` |
| `DATABASE_URL` | دیتابیس | `sqlite+aiosqlite:///./vpnbot.db` |
| `PANEL_MODE` | `mock` (تست) یا `pasargad` | `mock` |

> ⚠️ فایل `.env` هرگز نباید کامیت/پوش شود (در `.gitignore` هست).

### 🐳 اجرا با Docker

```bash
cp .env.example .env   # تنظیمات را بگذارید
docker compose up -d --build
```

## 🛠 پنل ادمین (داخل تلگرام)

### چطوری وارد شوم؟

1. در `.env` مقدار `ADMIN_IDS` را برابر آیدی عددی خودتان بگذارید (مثلاً `ADMIN_IDS=8581608010`).
2. ربات را ری‌استارت کنید.
3. در ربات دستور `/start` بزنید → در کیبورد پایین دکمه **«🛠 پنل مدیریت»** ظاهر می‌شود.
   - یا مستقیم بنویسید: `🛠 پنل مدیریت` (این متن دقیق).
4. اگر ادمین نباشید این دکمه اصلاً نمایش داده نمی‌شود و دستور `adm:` جواب نمی‌گیرد.

### بخش‌های پنل

| بخش | کار |
|---|---|
| 📊 آمار کاربران | کل/امروز/هفته/ماه، مسدودها، تست‌ها |
| 🛒 آمار خرید | سفارش‌ها، فروش روز/هفته/ماه، پرفروش‌ترین |
| 🧾 رسیدهای در انتظار | تأیید ✅ / انتظار ⏳ / رد ❌ (با دلیل) |
| 📦 کانفیگ‌های ارسال‌نشده | تلاش مجدد ساخت یا عودت به کیف پول |
| ربات/فروش/زیرمجموعه/تست | روشن/خاموش کردن هر بخش |
| 📢 کانال اجباری | تنظیم کانال + لینک + تست عضویت |
| 💳 اطلاعات کارت | شماره کارت (با اعتبارسنجی) + صاحب کارت |
| 🛍 قیمت سرویس‌ها | تغییر قیمت/حجم/مدت + فعال/غیرفعال |
| ➕ سرویس جدید | افزودن پلن جدید |
| ⚙️ تنظیم پنل VPN | حالت mock/pasargad + URL + API Key + تست اتصال |
| 📚 آموزش‌ها | افزودن/ویرایش/حذف آموزش |
| 🔍 جستجوی کاربر | کارت کاربر + تغییر کیف پول + مسدودسازی |
| 👥 مدیریت ادمین‌ها | افزودن ادمین (فقط سوپر ادمین) |
| 🧮 لاگ رخدادها | Audit Log عملیات ادمین |
| 📨 پیام همگانی | ارسال متن/عکس به همه کاربران |

### اگر پنل ادمین را نمی‌بینید (عیب‌یابی)

1. **`ADMIN_IDS` در `.env` درست است؟** باید آیدی عددی خودتان باشد (با `/myid` در ربات بگیرید).
2. ربات را بعد از تغییر `.env` **ری‌استارت** کرده‌اید؟ (`pkill -f app.main` سپس `python -m app.main`)
3. دکمه فقط بعد از `/start` اضافه می‌شود.
4. لاگ را ببینید: `tail -f logs/bot.log`

## 🔌 اتصال پنل پاسارگاد

کد به‌صورت Adapter طراحی شده؛ تا زمانی که مستندات API پنل را بدهید، حالت `mock` کانفیگ آزمایشی می‌سازد تا همه فلوها تست شوند. برای اتصال واقعی:
1. از پنل ادمین: ⚙️ تنظیم پنل VPN → حالت `pasargad` + URL + API Key
2. فایل `app/vpn/pasargad.py` طبق مستندات تکمیل می‌شود (بقیه سیستم دست‌نخورده می‌ماند).
